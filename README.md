# hello-world

Simple C programs for practice.

| File | What it does |
|------|--------------|
| `avijeet` | Prints "Hello World" |
| `add_numbers.c` | Adds two numbers |
| `even_odd.c` | Checks if a number is even or odd |
| `factorial.c` | Calculates the factorial of a number |
| `fibonacci.c` | Prints the Fibonacci series |
| `calculator.c` | Simple +, -, *, / calculator |

## App pages (`app/` folder)

A simple food-ordering flow made with HTML, CSS and JavaScript:

| File | What it does |
|------|--------------|
| `app/login.html` | Login page with email/password checks and show/hide password |
| `app/menu.html` | Menu with categories, add/remove items and a live cart |
| `app/payment.html` | Payment form with order summary, card formatting and checks |
| `app/style.css` | Shared styles for all three pages |

Open `app/login.html` in a browser to try it. The payment page is a demo only:
for real payments, connect a provider such as Stripe or Razorpay.

## How to run the C programs

```bash
gcc factorial.c -o factorial
./factorial
```
